# Интеграции: состав и реальная готовность

Три базовые интеграции из ТЗ: Cloudflare, Canva, Figma. Ниже дополнительно выбраны 30 сервисов по задачам AZRAIL. Это архитектурный backlog, не ложный каталог уже подключённых аккаунтов.

Cloudflare используется исполняемым Worker, D1, R2, KV, Workers AI и опционально Sandbox. В 1.3 добавлен общий MCP gateway с bearer и OAuth Code+PKCE; отдельные подтверждённые сценарии Canva/Figma приложения ещё не реализованы. См. [CONNECTORS_RU.md](CONNECTORS_RU.md). Плагины Canva, GitHub и Vercel в ChatGPT не становятся автоматически API-ключами пользователей развёрнутого SaaS.

Для каждого адаптера необходимы: проверенный способ доступа, OAuth/scopes или ключ конкретного tenant, зашифрованное хранение, отзыв, timeout, idempotency, политика вывода данных, лимит, журнал и реальный smoke. Ни ссылка, ни логотип не считаются интеграцией.

Приоритет: GitHub → Figma/Canva → Sentry → платёжный провайдер → Telegram → импорт данных → музыкальные источники. Доступность страны, аккаунта, тарифов и условия использования проверяются перед подключением соответствующего сервиса.

## Beatport

Часовой пояс задания пятницы должен быть выбран при настройке (например, `Europe/Kyiv`) и идемпотентный ключ `genre + chart_type + week`. Tracks и Releases/EP сохраняются отдельно, с позицией, URL, датой, артистом/лейблом и provenance. Источник должен предоставлять разрешённый доступ; обход блокировок и скачивание закрытого аудио не входят в архитектуру.

В предоставленных файлах нет готовой авторизованной live-интеграции Beatport и аудиодатасета. В этой поставке не добавлен фиктивный cron, который обещает получать Top-10, но не имеет рабочего источника. Следующий шаг — подтвердить источник метаданных и доступ к аудио; затем реализовать ingestion, spectral analysis и независимую оценку оригинальных генераций.

В 1.3 появился локальный спектральный анализ и сравнение двух загруженных файлов. Он не подключён к Beatport автоматически. Прямое чтение публичных чартов в этой проверке завершилось HTTP 403; реальные chart-данные не получены.
