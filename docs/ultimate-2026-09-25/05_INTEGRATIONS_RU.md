# Каталог 33 интеграций

Обязательные Cloudflare, Canva и Figma дополнены 30 сервисами под разработку приложений, данные, коммерцию, исследования, коммуникацию и мультимедиа. Это целевой каталог адаптеров. Подключённые к текущей сессии инструменты не становятся автоматически частью развёрнутого AZRAIL.

В коде AZRAIL существуют адаптеры Cloudflare и GitHub. Остальные позиции требуют реализации, регистрации приложения, разрешений владельца и проверки в целевой среде. Документационные ссылки служат отправной точкой; конкретные OAuth scopes выбираются по используемым методам актуальной версии API.

## Общий путь подключения

1. Пользователь выбирает задачу или сервис. Система показывает, что получит приложение и какие данные понадобятся.
2. Сервер создаёт OAuth/connection flow, проверяет state и callback, привязывает подключение к владельцу и проекту. Для API-key используются серверные секреты.
3. Выполняется безопасная проверка чтения. Статус становится connected только после подтверждения.
4. Из каталога адаптера открываются только разрешённые действия. Публикация и отправка остаются отдельными правами.
5. Каждый вызов получает trace ID, idempotency key при необходимости, таймаут, бюджет и ограничение повторов.
6. При отзыве доступа прекращаются новые вызовы и удаляются или отключаются соответствующие credentials. Сохранённые артефакты обрабатываются по политике хранения.

MCP используется там, где доступен подходящий проверенный сервер. REST/GraphQL используется там, где он точнее или надёжнее. «Поддержка плагинов» означает общий протокол и работающий жизненный цикл подключения, а не произвольное выполнение кода из неизвестного пакета.

## Документационные точки входа

Ссылки и машинный каталог находятся в INTEGRATIONS.json. Для PostHog, Datadog, Neon и Stability AI часть страниц не удалось полноценно получить через текущий просмотр документации; перед реализацией нужны повторная проверка схем и authentication flow. Это не влияет на выбор их как кандидатов, но не позволяет объявить адаптеры готовыми.

Canva-концепт, созданный в текущей работе, подтверждает изготовление макета через отдельный инструмент. Он не доказывает интеграцию Canva Connect внутрь AZRAIL. Аналогично, чтение GitHub и Cloudflare в этой работе не меняет секреты и подключения развёрнутого приложения.
