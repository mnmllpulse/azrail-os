# Проверки и состояние выпуска

Пакет AZRAIL OS 0.8.0 содержит обновлённые исходники и законченную проектную спецификацию Ultimate. Он не является подтверждением готовности всех модулей или выполненного production deploy.

## Выполнено

- TypeScript: npm run typecheck завершён успешно.
- Автоматические проверки: 1004 теста в 42 файлах прошли после изменений маршрутизатора и политики моделей.
- Новые поведенческие проверки: OFF при настроенном Gateway, блокировка платной hosted-модели, прямой вызов Free без Gateway, Free-маршруты кода и планирования, отказ при отсутствующей схеме, проверка бюджета и свежести тарифа, сохранение расхода после OFF/ON, конкурентное резервирование, отказ при ошибке валидатора, честный размер каталога.
- JavaScript нового интерфейса прошёл node --check.
- npm audit по установленному lockfile: 0 известных уязвимостей в полученном отчёте. Это не доказывает отсутствие уязвимостей приложения.
- Ранее в этой работе основной Paid-конфиг прошёл Wrangler dry-run: gzip около 538 КиБ. Эта проверка не собирала Docker-образ и не выполняла deployment.

## Ограничения проверки

Пробная сборка отдельного Free-конфига остановлена автоматической проверкой разрешений. Указанная причина: возможная передача исходников или метаданных через Wrangler в sparrow.cloudflare.com без отдельного разрешения. Профиль Free включён как образец для отдельной новой установки, а не как проверенное развёртывание.

Полный локальный Worker ранее не стартовал из-за ошибки uv_interface_addresses. Установка браузера сначала столкнулась с сертификатами, затем загрузка браузерного архива вернула некорректный ZIP. Live E2E, браузерная проверка нового интерфейса и сборка Docker в этой среде не выполнены. Новая страница нуждается в приёмке на телефоне и компьютере с подключённой API.

Платные модели не вызывались для проверки. Cloudflare проверялся чтением метаданных; репозиторий GitHub — чтением package.json. Новые таблицы, секреты, Worker, контейнеры и платёжные настройки аккаунта в этой работе не менялись.

## Реализовано и спроектировано

В коде реализованы модельная политика, настройка OFF/ON, месячное резервирование платных текстовых вызовов, обновление каталога, обработка ошибки валидатора и новый рабочий экран. Сохраняются ранее добавленные роли, владение ресурсами, outbox, checkpoints и копии файлов.

В спецификации подготовлены расширенная мультиагентная архитектура, сравнение пяти агентов, сравнение пяти сред, десять функций песочницы, 33 интеграции, голос, графика, музыкальная лаборатория, сценарии, критерии приёмки, Roadmap и Master-промпт.

Не реализованы внутри AZRAIL: 31 новый внешний адаптер, live Beatport, аудиорендер, спектральное сравнение, Whisper endpoint, image endpoint, полноценный MCP connector gateway, точная общая смета ресурсов, сетевой firewall песочницы и публичный multi-tenant SaaS. Наличие документации и дизайна не подменяет эти компоненты.

## Финансовая граница

OFF проверяется в контуре текстовых моделей AZRAIL. Он не отменяет платный тариф аккаунта, R2, контейнеры, внешние сервисы, операции вне AZRAIL или уже отправленные запросы. Free-допуск модели не даёт безлимитного использования на Workers Paid. Для строгой эксплуатации только в бесплатной квоте требуется подтвердить тариф и все задействованные ресурсы отдельной установки.

Резервирование использует консервативную оценку входа и потолок выхода; оно не заменяет инвойс провайдера. Сложные тарифы, неизвестное usage и дополнительные ресурсы требуют дальнейшей реализации и сверки. Формулировка «100% отсутствие любых списаний» в интерфейсе не используется.
