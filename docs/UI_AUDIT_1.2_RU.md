# AZRAIL × MNMLL PULSE OS — интерфейс 1.2

Обновлено 30 сентября 2026. Основа — Unified 1.1.0, два различных пользовательских скриншота, прежний Ultimate и предоставленный `globe.html`. Изменены исходники и автономный HTML. Это обновление интерфейса; оно не делает незавершённые интеграции готовыми сервисами.

## Что изменено по шагам

| Шаг | Что обнаружено | Что сделано |
|---|---|---|
| 1. Знак | Курсивная буква «a» не соответствует выбранному знаку Ultimate | Перед AZRAIL размещён SVG: незамкнутый круг с вертикальной чертой. Чёткий контур без растрового изображения и внешней загрузки |
| 2. Типографика | Курсивный шрифт с засечками не соответствует нужному характеру | Прямой плотный гротеск, две строки «ОДНА ИДЕЯ. / ЦЕЛЫЙ МИР.», спокойный фиолетовый акцент. Arial/Helvetica/system fallback, без зависимости от Google Fonts |
| 3. Мобильная композиция | На присланном скриншоте глобус заходит в область текста; верхняя панель тесная | До 650 px шапка разбита на две строки, глобус расположен отдельным блоком под текстом. У поля запроса и быстрых действий сохранены заметные подписи |
| 4. Орбиты | Нужно явно противоположное вращение | Планета вращается по Y с периодом 360 секунд, общий носитель шести наклонённых орбит — по той же оси с обратным знаком и периодом 240 секунд |
| 5. Управление движением | Нет явной пользовательской паузы | Кнопка паузы 44×44 px, доступное имя и состояние. При системном reduced motion автоматическое движение отключается |
| 6. Жизненный цикл 3D | Нулевой размер контейнера и скрытые поверхности могут приводить к лишним кадрам | Отдельные проверки размера, видимости вкладки и пересечения экрана. Остановка кадров, ограничение DPR до 1.5 и частоты рисования примерно до 30 fps |
| 7. Отказ графики | Ошибка создания WebGL или потеря контекста не должна оставлять пустой блок | Статичный CSS-глобус с подписью «Упрощённый вид». Текст, навигация и форма сохраняются. Автовосстановление WebGL после потери контекста пока не реализовано |
| 8. Уведомления | Локальное уведомление перекрывало форму на телефоне | Сообщение о локальном просмотре перенесено в обычный поток страницы. Информационные уведомления закрываются через 6.5 секунды; ошибки остаются до закрытия кнопкой |
| 9. Навигация | Нажатие на бренд не гарантировало возврат из студии | Бренд открывает «Создать», активная вкладка получает aria-current. При уходе из студии освобождаются её медиа-ресурсы |
| 10. Поставка | В корне оставался список хешей прежнего AZRAIL 0.8.1 | Исторический `RELEASE_FILES.json` перенесён в `references/azrail-0.8.1/`. Актуальное содержимое ZIP описывает `SOURCE_MANIFEST.json` |

Код интерфейса: `ui/app.html`, `ui/app.css`, `ui/tokens.css`, `ui/app.ts`. Глобус: `ui/globe.ts`. Исходный HTML пользователя сохранён в `references/globe.html`.

Периоды вращения указаны для активного воспроизведения: при паузе, скрытой вкладке или невидимом глобусе время анимации не накапливается. При сильном торможении вкладки большие скачки времени ограничиваются, чтобы исключить резкое движение.

## Что проверено

- `npm run check`: сборка двух интерфейсов, TypeScript сервера и UI, **49 наборов / 1 082 теста**, без падений.
- Готовый автономный HTML выполняется в Happy DOM: навигация, локальный режим, возврат по логотипу и сценарии повторной отправки миссий.
- Три новых теста глобуса: противоположные знаки вращения; пауза/скрытая вкладка/нулевой размер/очистка; reduced motion; потеря и недоступность WebGL. Используется подставной WebGLRenderer: это проверка логики, а не изображения на GPU.
- `npm run build:check`: успешная упаковка Free Worker без отправки на Cloudflare. Живые ресурсы не создавались.
- `npm audit`: 0 известных advisory во всех категориях на момент проверки. Зависимости интерфейса не добавлялись.
- Контрольная сумма каждого файла поставки и CRC ZIP проверяются при упаковке. HTML содержит CSS и JavaScript внутри файла; для его внешнего вида не нужны соседние папки.

**Визуальный прогон не состоялся.** Две попытки `agent-browser`, включая debug, завершились до открытия страницы: `Daemon process exited during startup with no error output`. Поэтому нет подтверждения геометрии CSS, WebGL, микрофона и экспорта видео в настоящем браузере. Прежняя попытка Chromium также не дала страницу. Автотесты не заменяют эту проверку.

Логи и границы проверок: `docs/verification/` и `VERIFICATION.json`. Результаты платного Worker, provisioning и серверных проверок предыдущей версии указаны отдельно; новая облачная сессия не запускалась.

## Чего ещё не хватает — в порядке выполнения

1. **Визуальная приёмка на настоящем телефоне.** Проверить 320, 360, 390, 768 и 1440 px; отсутствие горизонтального скролла; клавиатуру и увеличение текста; скролл поверх глобуса; видимость формы; контраст, фокус и экранный диктор. Отдельно проверить Android `content://`: некоторые просмотрщики запрещают JavaScript. Корневой HTML покажет оформление, но ограничения просмотрщика невозможно отменить кодом страницы.
2. **Понятные статусы миссий.** Сейчас детали результата показываются в JSON. Нужны краткий результат человеческим языком, этапы, ссылка на артефакт и раскрываемые технические подробности. Состояния «пусто», «вход нужен», «сеть пропала» нужно выровнять во всех студиях; это следующий UI-этап.
3. **Живой цикл Cloudflare.** OIDC-вход → задача → сохранение проекта → перезагрузка телефона → продолжение → ZIP. Проверить разделение данных двух аккаунтов, лимиты и ошибки реального провайдера. Unit-тесты эту приёмку не заменяют.
4. **Слияние с актуальным GitHub.** Создать интеграционную ветку, сохранить presence/projects/protocol и миграции из main, выполнить staging и только затем обновлять домены.
5. **Завершение прежних студий.** Девять направлений нового UI имеют обозначенные действия, но это не весь старый PULSE. Алгоритмический WAV/MIDI — музыкальный эскиз, Canvas WebM — визуальная анимация; они не заменяют профессиональные generative music/video SDK.
6. **Рабочие внешние адаптеры.** Beatport Top-10 треков и Top-10 релизов/EP, Telegram, платежи, Canva/Figma OAuth, каталог доступных моделей и биллинг требуют реализации/проверки по отдельным контрактам. Покупка Canva Pro сама по себе не подключает её API к AZRAIL.
7. **Ресурсы и Sandbox.** Нужны подготовленные зависимости для Sandbox, проверка живой изоляции и восстановление backup. Resource Ledger ещё не сверяет все услуги Cloudflare и расход других приложений аккаунта; OFF блокирует сторонние AI-маршруты, но не гарантирует нулевой счёт аккаунта.

## Как открыть

Распаковать ZIP и открыть **корневой `index.html`**, либо скачать отдельный `AZRAIL_PULSE_Preview.html`. `ui/app.html` — шаблон разработчика с внешними assets, а не самостоятельный файл для просмотра. Для сайта используется сборка `site/`; команды и настройка описаны в `DEPLOY_RU.md`.
