## Пошаговые сценарии

**Сайт.** Вход → один запрос → карточка миссии → реальные шаги и результаты проверок. Через «Стиль проекта» можно изменить контракт текущего проекта; он применяется к последующей генерации. После потери сети «Обновить» продолжает просмотр той же миссии. ZIP проекта экспортирует созданные файлы, а не объявляет непроверенный сайт готовым SaaS.

**Подключение.** Оператор регистрирует сервис → пользователь проходит OAuth или вводит личный токен → проверка соединения → поиск tools → подготовка действия → просмотр параметров → подтверждение → сохранённый ответ. Неопределённый результат требует сверки у провайдера, а не слепого повтора.

**Аудио.** Студии → Аудиоанализ → файл и необязательный референс → Проанализировать → таблица измерений и полный JSON. Обрабатываются декодируемые моно/стереофайлы до 30 МБ и 15 минут. Спектр оценивается по максимум 128 распределённым окнам 4096 отсчётов, уровни — по полному PCM. Декодер браузера может менять sample rate и зависит от поддерживаемого кодека.

## Старые исходники и UI

`references/pulse-source` сохранён как материал для переноса. Legacy Firebase, старые контексты и patch-скрипты не импортируются в новый entrypoint и не попадают в каталог `site/`. Удалять их вслепую ради уменьшения числа файлов не требуется: текущую production-границу обеспечивает отдельная сборка. Это также означает, что кнопки несуществующего редактора не добавлялись только для видимости готовности.

Логотип-круг с чертой, строгая sans-serif типографика и встречное вращение планеты/орбит из 1.2 сохранены. В видеостудии также заменён прежний Georgia на прямой sans-serif.

Этот документ фиксирует завершённые изменения и открытые задачи. Он не объявляет всё содержание PDF выполненным и не заменяет проверку в вашем аккаунте.
