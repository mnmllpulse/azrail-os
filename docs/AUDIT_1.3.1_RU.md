# Пошаговый аудит AZRAIL × MNMLL PULSE OS — Unified 1.3.1

Завершён 3 октября 2026. Основа — Unified 1.3.0. Исправлены подтверждённые ошибки и изменена анимация по замечанию пользователя. Архив готов к проверке и настроенному развёртыванию; production-приёмка внешних сервисов остаётся открытой.

## 1. Целостность и охват

Исходный ZIP содержал 644 записи. Его CRC и SHA-256 всех 643 файлов манифеста совпали с рабочей копией в начале аудита. SHA-256 исходного ZIP: `d51d691e8d2ee36b9cc2925fe1089b16cb3ca2de845f374dac7a249d76befe70`.

Углублённо проверены OIDC, роли, повторы миссий и медиа, квоты, Ledger, экспорт R2, MCP, черновики, отображение миссий, аудио, анимация и деплой. Остальной код охвачен сборкой, TypeScript и существующими тестами. Инвентаризация не означает построчное чтение всех исторических исходников.

Активный frontend: `ui/` → `site/`. Исторический `references/pulse-source` не публикуется как приложение. Корневой `index.html` пересобран: CSS, JS, Three.js и геоданные встроены. Для локального просмотра открывайте его; исходный `ui/app.html` требует сборки.

## 2. Найденные ошибки и исправления

P1 — доступ, расходы, повреждение результата или блокирование выпуска. P2 — валидация и поведение интерфейса. Все пункты таблицы исправлены в 1.3.1.

| № | Приоритет | Ошибка | Исправление и доказательство |
|---|---|---|---|
| 1 | P1 | Cookie-вход превращал viewer в editor | Сессия сохраняет актуальную роль; viewer не получает operator. PUT черновика после понижения роли возвращает 403 без записи |
| 2 | P1 | Через 24 часа ключ принятой операции можно было занять снова; cron удалял также неопределённые записи | Автоматический повтор/удаление отключены. После истечения срока и cleanup тест получает pending либо replay без новой операции |
| 3 | P2 | Неверный JSON, null или числовой prompt давали 503 и могли навсегда занимать ключ | Ограниченная проверка JSON-объекта. Ошибки до отправки дают 400/413/429 и освобождают ключ; после отправки неопределённый результат удерживает блокировку повтора |
| 4 | P1 | Понижение DAILY_PROVIDER_CALLS не меняло текущий дневной бюджет | Лимит синхронизируется до резервирования. Значение 0 блокирует следующий вызов в тот же день; ранее обнаруженное превышение резерва остаётся блокирующим |
| 5 | P1 | ZIP-экспорт перекодировал двоичные файлы через UTF-8 | Чтение и упаковка байтов без преобразования. ZIP/unzip возвращает исходный массив с 0xFF/0x80 без изменений |
| 6 | P1 | Экспорт мог читать workspace одновременно с его изменением | Project lock, фиксация prefix, проверка ETag/размера и версии. Занятая блокировка или обнаруженная смена файла дают 409. Предел — 400 файлов, 16 МиБ исходных данных |
| 7 | P1 | Некорректный MCP tools/call, например `{}`, считался успехом | Проверяются content-блоки, structuredContent/isError и объявленная outputSchema. Некорректный ответ после отправки не разрешает слепой повтор |
| 8 | P2 | Загрузка черновика затирала текст, введённый во время ожидания GET | Новые правки сохраняются в форме; версия сервера обновляется для следующего CAS-сохранения. Параллельная загрузка/сохранение блокируется |
| 9 | P2 | Неподтверждённая оценка модели показывалась как пройденная проверка; cancelling не имел названия | Оценка результата и запуск тестов показываются отдельно по событиям. Есть «не подтверждена» и «Останавливаю задачу» |
| 10 | P2 | После 200 событий API скрывал конец длинной миссии | Возвращаются последние 200 событий в устойчивом хронологическом порядке. Проверены 205 событий с одинаковым временем |
| 11 | P1 | CI мог создать D1/KV/R2 до обнаружения отсутствующих OIDC-настроек | Локальные параметры и сборка UI проверяются до облачных изменений. Тест перехватывает подпроцессы и подтверждает отсутствие provisioning при ошибке входа |
| 12 | P2 | Аудио 8 кГц получало невозможную полосу 6000–4000 Гц | Номинальные границы отделены от `analyzedToHz`; недоступная полоса имеет null. Разные пределы Nyquist не сравниваются как одинаковые |
| 13 | P2 | Произвольный base64-текст провайдера сохранялся под видом PNG | До R2 проверяются размер и сигнатура PNG/JPEG/WebP. Неподходящий ответ не сохраняется как изображение; автоповтор блокируется. Это определение формата, а не полный декодер |
| 14 | P1, выпуск | Тест документированных API не учитывал модуль MCP и блокировал сборку | В сканирование добавлен реальный модуль маршрутов. Поведение подключений отдельно покрыто интеграционными тестами |
| 15 | P2 | Ошибка settlement после успешного ответа модели скрывала готовый результат | Ответ возвращается, полный резерв удерживается. Тест отказа записи подтверждает один вызов и сохранённый резерв |

Основные файлы: `src/unified/`, `src/lib/mission-admission.ts`, `src/lib/quota.ts`, `src/lib/event-store.ts`, `ui/`, `scripts/deploy-ci.mjs`. Новые проверки: `tests/audit-131.test.ts`, `tests/deploy-preflight.test.ts`; расширены существующие UI, globe, audio и регрессионные наборы.

## 3. Сфера и кольца

Сверен предоставленный `references/globe.html`, SHA-256 `8c941798ababb38f94283c69075cb3eb6fdf1d7ed0b9b9d2a80a2a9d4e163ae6`.

В оригинале заметное движение создают светящиеся спутники со скоростью 0,15–0,5 рад/с. В 1.3 их оборот занимал 100–185 секунд, поэтому композиция казалась почти неподвижной.

В 1.3.1 планета делает оборот за **180 секунд** вместо 360; носитель шести орбит — за **120 секунд** навстречу планете; спутники — за **18–36 секунд**. Точки стали заметнее, добавлен мягкий ореол, линии колец тоньше. Мобильный блок уменьшен с 224 до 184 px; на узких экранах — до 172 px.

Сохранены пауза, reduced motion, остановка вне видимой области и освобождение GPU-ресурсов. Это адаптация оригинального эффекта к встречному вращению: в исходнике плоскости колец не вращались. Без WebGL остаётся статичный упрощённый вид. Математические тесты углов не заменяют визуальную приёмку на телефоне.

## 5. Что ещё нужно сделать

1. **Production-контур:** OIDC на трёх доменах, реальные Workers AI/MCP, второй аккаунт, смена роли и восстановление задачи после закрытия телефона.
2. **Мобильная приёмка:** 320/390/768/1440 px, анимация/пауза, клавиатура, голос, сетевые ошибки и отсутствие WebGL.
3. **Восстановление backup:** D1, R2 и ключи на отдельном окружении. ZIP проекта не является копией базы.
4. **Финансовая сверка:** Neurons, media, Containers, storage, цены и invoice. Счётчик запросов не является полным денежным hard cap аккаунта.
5. **Reconciliation и retention:** успешные/неопределённые ключи теперь сохраняются без автоматического удаления. Нужны сверка с провайдером, операторские процедуры и оценка роста D1. Уже удалённые старой версией записи не восстанавливаются.
6. **Долговечные процессы:** fencing tokens, мультимодальный DAG, отмена у провайдера, OAuth refresh и ротация vault-ключа.
7. **Специализированные функции:** Beatport Top-10 треков и релизов, музыкальный runner/stems/mastering, подтверждённые Figma/Canva/Telegram/платёжные адаптеры, visual editor и оставшиеся студии.
8. **Интеграция с GitHub:** ранее обнаружено расхождение с `mnmllpulse/azrail-os`. Нужен свежий diff в отдельной ветке; не заменяйте main целиком. Историческое сравнение — `GITHUB_CANVA_REVIEW_RU.md`.

Полная матрица первоначального задания — `TASK_1.3_RU.md`. MCP gateway не подтверждает готовность всех 33 интеграций. WAV/MIDI и спектральный анализ не означают завершённость полного музыкального AI-продакшена. Лидерство проверяется отдельными воспроизводимыми сценариями.
