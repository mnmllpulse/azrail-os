# Исходные материалы

`globe.html` — предоставленный автором исходный глобус. Рабочая адаптация: `ui/globe.ts`.
`pulse-source/` — сохранённые исходники предыдущего PULSE, включая незавершённые панели и legacy.
Они не входят в production-assets, не импортируются новым Worker и не объявлены рабочими интеграциями.
Сохранены для поэтапного переноса: функциональность старых панелей не считается автоматически завершённой.
AZRAIL 0.8.1 находится в основном дереве `src/`; новые общие модули — `src/unified/`.

В рабочем глобусе карта заменена на локальную геометрию из `world-atlas@2.0.2`
(`countries-110m.json`, Natural Earth), преобразованную через `topojson-client`.
Атрибуция и лицензии: `WORLD-ATLAS-README.md`, `WORLD-ATLAS-LICENSE.txt`, `THREE-LICENSE.txt`.
Исходная ссылка на карту из `globe.html` в рабочем приложении не используется.
