# DARK MNMLL PULSE OS · Cloudflare edition 1.0.0-cf

Перенос исходного проекта на Cloudflare Workers + Static Assets, D1, R2 и Workers AI. Сборка предназначена для личного пространства владельца и трёх доменов.

**Начните с [DEPLOY_CLOUDFLARE_RU.md](DEPLOY_CLOUDFLARE_RU.md).** Отчёт: [AUDIT_RU.md](AUDIT_RU.md). Реальные границы модулей: [CAPABILITIES_RU.md](docs/cloudflare-2026-09-26/CAPABILITIES_RU.md).

| Домен | Роль по умолчанию | Старт после входа |
|---|---|---|
| mnmllpulse.com | Создание / основная OS | `/dashboard` |
| mnmllpulse.org | Знания / системная книга | `/book` |
| pulse-labs.org | Лаборатория | `/studio/lab` |

Роли — выбранная при переносе схема, которую можно поменять в `shared/platform.ts`. Все домены обслуживает один Worker; D1 и R2 общие. Вход на каждом домене отдельный. Общая регистрация пользователей и междоменный SSO не реализованы.

## Что перенесено

- Сервер API в `worker/`; в production больше не запускается Express/Node daemon.
- Вход владельца, серверные сессии, защита операций от сторонних Origin, ограничения запросов.
- История чатов, настройки, учёт попыток генерации и метаданные файлов в D1; сами файлы в R2.
- Адаптеры Workers AI: текст Llama, код Qwen, изображения FLUX, расшифровка Whisper.
- Текстовая совместная работа нескольких моделей с сохранением результата. Она не запускает shell и не создаёт развёрнутый продукт сама по себе.
- Раздельная загрузка тяжёлых страниц, новый входной экран, конфигурация трёх доменов, GitHub-проверки.

Старые студии сохранены. Часть возможностей в них остаётся прототипами. Имитируемые терминал, деплой и оплачиваемые тарифы не выдаются новым сервером за выполненные операции. Полный список ограничений — в отчёте.

## Локальная проверка

Требуется Node.js 24.

```sh
npm ci
npm run check
npm run audit:source
```

`check` выполняет проверку TypeScript, тесты и локальную сборку. Не публикует проект и не обращается к платным AI API. Тесты используют SQLite и тестовые адаптеры D1/R2/AI; это не проверка живого аккаунта Cloudflare.

Для просмотра интерфейса с заведомо тестовыми AI-ответами:

```sh
npm run build
node --import tsx tests/preview-local.ts
```

Адрес `http://localhost:4173`; тестовый ключ указан в `tests/support.ts`. Он существует только в локальном стенде, не в production Worker. Все данные стенда пропадают при завершении процесса. Браузер должен поддерживать Secure cookies на localhost. `npm run preview` отдельно показывает только статику, без API.

Для разработки в Wrangler: скопируйте `.dev.vars.example` в `.dev.vars`, задайте собственный ключ, выполните `npm run db:migrate:local`, затем `npm run dev`. Запросы Workers AI при такой разработке могут обращаться к аккаунту Cloudflare; бесплатный локальный AI здесь не эмулируется.

## Production

Подключите GitHub-репозиторий в **Cloudflare Workers Builds**, а не публикуйте один `dist/` как Pages-сайт. Build command: `npm run check`. Production deploy command: `npm run deploy:ci`. Перед первой публикацией нужны ваши D1/R2, секрет `OWNER_ACCESS_KEY` и проверка доменов. Подробности — в инструкции.

`legacy/` — история старого сервера и заменённых модулей. Не является запускаемым второй сервером. Не переносите его старые секреты/команды обратно в production. `system_docs/` и `DARK_MNMLL_PULSE_OS.md` описывают исходный замысел, а не подтверждённую функциональность новой версии.
