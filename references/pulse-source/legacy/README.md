# Исторический исходник — не production

Эта папка сохраняет исходный Express/daemon, старые примеры конфигурации, прежний Worker stub, локальные patch-скрипты и заменённые frontend-модули.

Новый вход: `worker/index.ts`; конфигурация: корневой `wrangler.toml`. `legacy/` исключён из active TypeScript-check и не импортируется новой сборкой Worker. npm-команд для запуска исторического сервера нет.

Здесь сохранены известные проблемы исходника: небезопасные примеры токенов, имитации исполнения, прежний middleware и устаревшие предположения о развёртывании. Файлы нужны для сравнения и переноса оставшихся функций; их присутствие не означает поддержку или готовность.
