# План продолжения

Приоритеты зависят от цели первого запуска: сейчас это личное пространство владельца. Публичный SaaS потребует другого уровня пользователей, биллинга и изоляции данных.

| Этап | Изменение | Критерий завершения |
|---|---|---|
| 1. Приёмка Cloudflare | Проверить ресурсы, сделать первый deploy, проверить три hostname, телефон и реальные модели | Вход/выход, текст, история и файл работают на всех доменах; нет ошибок API/console в выбранных сценариях |
| 2. Убрать остатки демонстраций | Пройти 83 файла из индекса маркеров; отделить декоративные эффекты от метрик и реальных действий | Каждая кнопка выполняет проверяемое действие либо имеет явный статус «прототип/не подключено»; случайные числа не названы измерениями |
| 3. Общее пространство проектов | Перенести localStorage-проекты/настройки/агентов в D1/R2, добавить import/export и версии | Проект, созданный на телефоне через .com, виден после входа через .org; существующие данные импортируются без потери |
| 4. Настоящий исполнитель | Изолированный build/test runtime с отдельными полномочиями, лимитами времени и сети | Вредный preview не читает сессию/секреты; тестовое приложение устанавливается, собирается, тестируется и экспортируется |
| 5. Durable задачи | Workflows/Queues либо другой подтверждённый durable runner, состояния, cancel/resume, идемпотентность | Закрытие вкладки не теряет задачу; повтор доставки не дублирует платные операции |
| 6. Модели и стоимость | Синхронизация каталога, capability registry, AI Gateway, provider usage и бюджетные reservations | OFF блокирует все внешние вызовы на сервере; параллельные задачи не превышают заданный денежный предел; сумма сверена с провайдером |
| 7. Медиа | Рабочие music/video API, realtime voice, экспорт WAV/stems/video, файл-ориентированные задания | Реальный файл скачивается и открывается; артефакт связан с запросом, моделью и фактической стоимостью |
| 8. Интеграции | GitHub/Figma/Canva/Cloudflare и нужные сервисы по приоритету; OAuth, минимальные scopes, ревокация | Каждый connector проходит полный read/write сценарий; разрешения и ошибки видны; отправка/публикация требует намерения владельца |
| 9. Beatport | Top-10 tracks + Top-10 releases/EP, пятничные snapshots и анализ разрешённых reference-аудио | Данные имеют дату/источник; парсер проходит regression fixtures; спектральные метрики воспроизводимы; синтез оригинальный |
| 10. Публичный продукт | Multi-user, Access/MFA, роли, tenancy, платежи, резервные копии и наблюдаемость | Данные двух пользователей изолированы тестами; verified webhook и возвраты работают; восстановление реально выполнено на staging |

Число файлов в этапе 2 — результат лексического поиска этой версии, не число подтверждённых дефектов. Порядок 4–8 можно менять после выбора приоритетного продукта. Готовность и лидерство оцениваются реальными задачами и результатами, а не числом кнопок или названий моделей.

## Измеримые цели продукта

- Вход и первый осмысленный запрос без чтения технической документации; отдельная проверка на телефоне.
- Метрики p50/p95 времени ответа, успех выполнения задач, доля повторных генераций, цена успешного результата.
- UI: keyboard navigation, focus/escape, читаемость и контраст, отсутствие горизонтального переполнения на 360–430 px.
- Код: воспроизводимая сборка, содержательные тесты, зависимости без известных критических проблем, изоляция preview.
- Дизайн: единая типографика/палитра/поведение компонентов, затем поэтапная переработка старых студий под новый входной экран.
- Никаких гарантированных «$0», «любой продукт», «100% автономность» без технических ограничителей и независимой приёмки.
